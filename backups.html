Vimuktam · Administration

Repository & Storage Control Centre

A private set of doors into Vimuktam's working repositories, document store, media storage and independent recovery systems. Primary systems remain the sources of truth; backup systems remain independent recovery points.

Primary repositories & storage

Website Repository The complete primary GitHub repository containing the Vimuktam website source, Company docs and associated project material.
Primary · GitHub · Technical access
The underlying GitHub account retains its own authentication and two-step verification.
Company Documents Your everyday document cupboard inside the primary GitHub repository: BCPs, policies, agreements, PDFs, Markdown archives and other company material.
Primary · GitHub / Company docs · Manual document filing
Add or manage documents directly in the Company docs area; GitHub remains the underlying system.
Main R2 Primary media and publication storage for images, publications and other larger files that are not kept in GitHub.
Primary · Cloudflare R2 · Manual file management
Cloudflare remains responsible for authentication, account security and R2 bucket management.

Independent recovery systems

Bitbucket — Backup 1 Independent copy of the primary GitHub repository for recovery if GitHub becomes unavailable, compromised or inaccessible.
Backup 1 · Daily at 2:00 AM · Normal Git history retained
No automatic 90-day Git pruning. Storage can be reviewed and managed manually if needed.
GitLab — Backup 2 / Standby Second independent copy of the GitHub repository for recovery and standby use.
Backup 2 · Standby · Daily at 18:00 UTC + push/manual runs · Normal Git history retained
No automatic 90-day Git pruning. Storage can be reviewed and managed manually if needed.
R2 Backup Independent disaster-recovery copy of Main R2 with automatic backup, 90-day retention for deleted files and historical versions, and restoration controls.
Recovery · Cloudflare R2 · 9.90 GB operational ceiling · Daily + manual backup
The backup console displays used/available storage, deleted-file status, historical versions, manual deletion and restore-to-main controls.
