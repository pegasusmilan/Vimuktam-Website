Vimuktam · Administration

Repository & Storage Almirahs

A simple Vimuktam-facing layer over the repositories, working storage and recovery systems behind the company. The intention is that routine filing happens here; the underlying services remain infrastructure.

Primary working spaces are for everyday filing and operation. Recovery spaces are independent protection layers and are normally used only when needed.

Primary · Everyday filing

01 · PRIMARY

Website Repository

The complete Vimuktam GitHub repository, presented through a Vimuktam-facing portal for routine viewing and management.

GitHub · Full repository
The underlying GitHub interface remains available from inside the cabinet when technically required.
02 · PRIMARY

Company Documents

The everyday filing cupboard for BCPs, policies, agreements, PDFs, Markdown archives and other company documents.

GitHub · Company docs
Documents can be filed directly into the Company docs/ folder from inside the cabinet.
03 · PRIMARY

Main R2

The working media and publications cupboard for images, publications and other larger files.

Cloudflare · Main R2
Its Vimuktam-facing upload and filing portal will be connected next.

Recovery · Independent protection

04 · RECOVERY

Bitbucket · Backup 1

Independent Git recovery copy of the primary repository. Normal Git history is retained.

Bitbucket · Daily backup
No automatic 90-day Git pruning. Storage can be reviewed manually.
05 · RECOVERY

GitLab · Backup 2 / Standby

Second independent Git recovery and standby copy of the primary repository. Normal Git history is retained.

GitLab · Scheduled + push/manual
No automatic 90-day Git pruning. Storage can be reviewed manually.
06 · RECOVERY

R2 Backup

Disaster-recovery copy of Main R2 with automatic backup, historical/deleted-file retention and restore controls.

Cloudflare Worker · 9.90 GB ceiling
Backup console provides storage status, backup, deletion/history and restore controls.
